## 📖 Overview
This directory is dedicated to the **automated verification of the Q-Vault Sovereign OS**. It uses `pytest` and `pytest-qt` to ensure that core system components, security boundaries, and UI interactions remain deterministic and secure.

## 🛠️ Testing Framework
- **Primary Tool**: `pytest`
- **UI Testing**: `pytest-qt` (for asynchronous widget signals)
- **Mocking**: `unittest.mock` (for simulating hardware tokens and Rust core)

## 📁 Test Structure
- `test_security.py`: Verifies Auth state transitions and Argon2id hashing.
- `test_vfs.py`: Validates Unix-parity permissions and Inode integrity.
- `test_event_bus.py`: Ensures source-authority and event routing accuracy.

## 🚀 Running Tests

